1. 行列曲線比較の短い証明

正定値のC²曲線Fが F″−F′F⁻¹F′ ≥ 0 を満たすとします。結論は F(t) ≤ F(0)#ₜF(1) です。定数の合同変換でF(0)=Iに正規化し、B=F(1)、C=(log B)/2とします。

ε>0に対して E(t)=exp(−εt(1−t))F(t) と置きます。積の微分から正確に

E″−E′E⁻¹E′ = exp(−εt(1−t))·(F″−F′F⁻¹F′+2εF) ≥ 2εE

が成り立ちます。R(t)=exp(tC)、S(t)=R(t)⁻¹E(t)R(t)⁻¹と置くとS(0)=S(1)=Iです。Sの最大固有値の区間全体での最大をαとします。有限次元と連続性から最大が存在します。

α>1なら最大は内点t₀で達成され、単位ベクトルvを S(t₀)v=αv と選べます。全てのtでS(t)≤αIなので、固定したvによる実数関数 ⟨v,S(t)v⟩ はt₀で最大を取り、⟨v,S″(t₀)v⟩≤0です。

以下の量を全てt₀で評価します。

Δ = R⁻¹(E″−E′E⁻¹E′)R⁻¹ ≥ 2εS a = S′v, c = Cv, Sv = αv ⟨v,S″v⟩ = ⟨v,Δv⟩ + ⟨a+(αI−S)c, S⁻¹(a+(αI−S)c)⟩ + 2⟨c,(αI−S)c⟩

この等式は次の積の微分を展開してSv=αvを代入するだけです。非可換な積の順序を保っています。

R⁻¹E′R⁻¹ = S′+CS+SC R⁻¹E″R⁻¹ = S″+2(CS′+S′C)+C²S+2CSC+SC²

具体的にはq=a+(S+αI)cと置くと、右辺の二階項から ⟨q,S⁻¹q⟩−4 Re⟨c,a⟩−2α‖c‖²−2⟨c,Sc⟩ を得ます。q=[a+(αI−S)c]+2Scを代入して平方完成すると上の恒等式になります。この計算は任意の有限次元で同じです。

S⁻¹>0、αI−S≥0より、最後の2項は非負です。従って ⟨v,S″v⟩≥2εα>0となり、最大点の二階微分の符号と矛盾します。よってα≤1、E(t)≤Bᵗです。ε↓0と最初の合同変換を戻すことで結論を得ます。

この証明には幾何平均の順序単調性、一様格子、Taylor余項の形式化が不要です。有限次元の最大固有値と、行列指数関数の微分・平方完成が必要です。2×2の一般の複素Hermitian成分による平方完成の例もSymPyで厳密に残差0を確認しましたが、全次元の根拠は上の代数的導出です。

2. 停留GramとPW/KM

複素Hilbert–Schmidt空間H=Mᵣ₊ₛ(ℂ)、ブロック代数𝓑=Mᵣ⊕Mₛ、等長包含V:𝓑→H、Γ=V*とします。前提は

T > W > 0, W∈𝓑, log W = Γ(log T)+Λ, Λ=λ₀Iᵣ⊕λ₁Iₛ, P = Γ(T)−W > 0

Λがブロック代数の中心にあるため、ブロック行列Hと交換します。従って生成子圧縮が成り立ちます。

K = L_(log T)−R_(log T), k = (L_(log W)−R_(log W))|𝓑 V*KV = k

Cₜ=Q_T(t)=L_TᵗR_T¹⁻ᵗ、Bₜ=Q_W(t)|𝓑、Fₜ=V*CₜV−Bₜとします。左・右乗算は可換なので Cₜ′=CₜK、Bₜ′=Bₜk です。

0≤t≤1における正作用素の冪の順序性からQ_T(t)−Q_W(t)>0です。Q_Wが対角・非対角ブロック空間を保存することも使うと、Dₜ=Cₜ−VBₜV*>0です。

[[F,F′],[F′,F″]] = [V,KV]* · D · [V,KV] ≥ 0

右辺の4ブロックは順に、V*CV−B、V*CKV−Bk、V*CKV−Bk、V*CK²V−kBkです。K,Cおよびk,Bの可換性とV*KV=kを使えば、左辺の微分と一致します。圧縮と冪を交換する仮定は使いません。

Schur補からF″−F′F⁻¹F′≥0。前節の曲線比較、F(0)=R_P|𝓑、F(1)=L_P|𝓑と左・右乗算の可換性よりF(t)≤Q_P(t)|𝓑です。これがPW、積分するとKMです。

PW: V*Q_T(t)V ≤ Q_P(t)|𝓑 + Q_W(t)|𝓑 KM: V*Ω_TV ≤ Ω_P|𝓑 + Ω_W|𝓑, Ω_X = ∫₀¹ Q_X(t)dt

GramのLean補題ではC,K,B,k,Vと各恒等式・DのPSDを明示した引数にしています。行列冪の順序性、CFC微分、停留条件からそれらの引数を供給する解析的な接続はまだLeanに入っていません。

3. 双対最小化とHessianの符号

Ψ(X)=Tr(X log X)、固定したλ₀,λ₁<0に対して

f_J(W) = Ψ(W)−Ψ(J+W)−Tr(ΛW), W∈𝓑, W≥0 G_Λ(J) = Ψ(ΓJ)+min_W f_J(W)

とします。R=Tr W、b=Tr J、a=min(−λ₀,−λ₁)>0と置くと、logの順序性から f_J(W)≥aR−b(1+log(R+b+1))→∞です。これはJがコンパクト集合を動くときも一様であり、最小値の存在と連続性を得ます。

J>0では境界のWにε倍の核射影を足すとε log εの項が他のO(ε)項を上回って目的を減らすため、最小点はW>0です。またD log X=Ω_X⁻¹とΩ_(J+W)>Ω_WからWのHessianは厳密に正となり、最小点は一意です。陰関数定理でJに関して滑らかになります。

T=J+W、P=ΓJ、A=Ω_T、B=Ω_W|𝓑、C=Ω_P|𝓑、E=B⁻¹−V*A⁻¹V>0として、全目的関数のHessianは

[[VC⁻¹V*−A⁻¹, −A⁻¹V], [−V*A⁻¹, E]]

です。最小点を微分してW方向を消去するとSchur補になり、Woodburyを使って

D²G_Λ = VC⁻¹V*−A⁻¹−A⁻¹VE⁻¹V*A⁻¹ = VC⁻¹V*−(A−VBV*)⁻¹

となります。このマイナス符号と2つの式の一致はLeanで確認しました。

Z=A−VBV*>0と置くと、KMからV*ZV≤Cです。Z¹ᐟ²V(V*ZV)⁻¹ᐟ²は等長写像なので、その像への射影≤IをZ⁻¹ᐟ²で合同変換すれば Z⁻¹≥V(V*ZV)⁻¹V*。逆行列の順序反転も使うと

Z⁻¹ ≥ V(V*ZV)⁻¹V* ≥ VC⁻¹V* ⇒ D²G_Λ ≤ 0

です。線分への制限でJ>0上の凹性を得て、最小値の連続性でPSD境界まで延長します。Ω_Xは随伴操作を保存します（tと1−tの積分対称性）。その逆も保存するため、この複素作用素の式を実Hermitian方向のHessianへ制限できます。

固定するのはΛです。外側のトレースy,wを固定した別の値関数の凹性や、αルートの4行列の同時凹性R2は使用していません。

4. スカラー化とTC4への符号

J≥0で2つのブロックトレースをx,z>0に固定します。rank J=q≥2なら、support上のHermitian行列の実次元q²>2に対して2本のトレース制約を課しても非零方向Hが残ります。Tr H=0なのでHは不定です。J+tHがPSDでいられる区間の両端でrankが落ち、Jを両端の凸結合に分解できます。有限回の再帰で、同じx,zを持つrank1の有限分解を得ます。

rank1では独立なブロックユニタリで2つの活性方向へ移し、Wを補空間への符号反転で平均します。f_Jの凸性から平均は目的を増やさず、残る補空間ではΨが相殺して−Tr ΛW≥0だけになります。よって補空間の最小値は0です。

j=[[x,√xz],[√xz,z]]、L=j+diag(y,w)、y,w>0とし、λ₀=log y−(log L)₀₀、λ₁=log w−(log L)₁₁を選びます。rank1更新の逆行列公式とlogの積分表示から両係数は厳密に負です。スカラー目的の勾配がこのΛに一致し、凸性から(y,w)が全域の最小点です。

凹性によるrank1下界と、最小値の定義による任意Wでの上界を合わせ、Tr ΛW=λ₀y+λ₁wを相殺します。

Ψ(AA*)+Ψ(BB*)+Ψ(CC*)+Ψ(DD*)−Ψ(MM*) ≥ x log x+y log y+z log z+w log w−Ψ(L)

Ψ(R)=a log a−aS(R/a)、Tr MM*=Tr L=1を代入すると、所望のTC4の向きになります。rank1還元で用いる凹性の向きもG(J)≥平均G(rank1)で一致しています。
